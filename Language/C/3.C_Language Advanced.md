# C_Language Advanced

## 32个关键字

- 数据类型：`auto char short int long float double  struct enum void union`  

- 修饰类： `signed unsigned static const volatile extern ` 

- 语句控制类：`if else for do while  goto switch case default continue break `

- 其他：`register typedef sizeof`

- 特别说明

  - `register`: 尽可能的将变量存于CPU内部寄存器，即不能通过内存寻址访问，所以不能使用取值运算符

  - `sizeof`: 是关键字，并非函数

  - `static`: 静态局部变量，在函数体里面定义的，就只能在这个函数里用了，同一个文档中的其他函数也用不了。由于被static 修饰的变量总是存在内存的静态区，所以即使这个函数运行结束，这个静态变量的值还是不会被销毁，函数下次使用时仍然能用到这个值

  - `switch case`: case后面使用整型或者字符类型（本质也是整型）

  - `extern`: 主要用于声明外部变量，初始化意味着申请内存，即定义；

    ```C
    // global.c
    int value = 20;
    
    // global.h
    extern int value;
    
    // .c
    #include "global.h"
    value++;
    ```

    

  - `struct`: 打包相关参数，CPU处理函数参数大于4个会降低效率。

  - `union`: 用法和`struct`使用相似，主要用于压缩空间，在同一时间不被同时用到的数据可以使用`union`,空间大小为最大长度的数据成员（此外还需考虑大端 【 高位字节存储在低地址 】 和小端【高位字节存储在高地址的影响】）

    ```C
    int CheckSystem()
    {
        union check{
            int i;
            char ch;
        } c;
        c.i = 1;
        printf()
        return (c.ch==1);
    }
    
    // main.c
    printf("System is %s-endian\n", checkSystem() ? "little" : "big"); // 判定首地址的值，大端模式时首地址为0；小端为1；
    ```

  - `enum`: 定义一组整型常量，常量用大写，常用于状态机，数组映射，通信协议命令码

  - `const`：有类型检查、受作用域限制、安全性高。适合参数配置、常量变量。**修饰谁，谁不可变**

  - `typedef`: 类型别名，有类型检查，有作用域，

  - `#define：` 文本替换，最轻量、预处理替换、无类型检查。适合硬件寄存器、条件编译。

  - `volatile` 易变的，会被程式所改变，所以禁止优化处理

    ```C
    int flag =0;
    // 可能会被优化为死循环
    while(flag==0){
        // code
    }
    ```

    

## 内存管理（`stdlib.h`）

- 基本概念：

  - 代码区（TS）：存放程序的可执行代码
  - 数据区（DS）：`已初始化（存放程序中已初始化的全局变量和静态变量），未初始化（存放程序中未初始化的全局变量和静态变量）`

  - 堆区（Heap）：用于动态分配内存（通过 `malloc()`、`calloc()`、`realloc()` 等函数），手动释放内存

  - 栈区（Stack）：存放局部变量、函数调用的参数、返回地址等。栈用于管理函数调用的过程，自动释放内存

  - 命令行参数（ENV and Arguments）：存放程序的命令行参数（`argv`）和环境变量（`envp`）

  - 内存映射（MMS）：用于存放通过 `mmap()` 函数映射的文件或共享内存区域

  - 内存泄漏：如果使用 `malloc()` 或 `calloc()` 后没有正确使用 `free()` 释放内存，就会导致内存泄漏，长期下去可能会占满整个堆区域，导致程序崩溃

- 内存管理函数使用

  ```C
  // 动态内存分配（堆区）void* malloc(size_t size);
  int *arr = (int *)malloc(5 * sizeof(int)); // 分配5个整数内存
  if(arr==NULL){ // malloc
      // code
  }
  
  memset(arr, 0, 5 * sizeof(int)); // 初始化
  
  
  // calloc() 会分配动态内存，并初始化为0；
  int *arr = (int *)calloc(5, sizeof(int)); // 分配5个整数的内存，并初始化为零
  if (arr == NULL) {
      // 错误处理
  }
  
  // realloc调整分配的内存
  int *arr = (int *)malloc(5 * sizeof(int)); // 初始分配
  arr = (int *)realloc(arr, 10 * sizeof(int)); // 调整为10个整数大小
  if (arr == NULL) {
      // 错误处理
  }
  
  // free()释放内存
  free(arr);  // 释放动态分配的内存
  arr = NULL; // 避免悬空指针
  
  ```

  ```C
  int main(void)
  {
      char *p;
      p = (char *) malloc(100); // 申请100字节堆空间
      p = (char *) realloc(150); // 新增50字节，共150字节堆空间
      free(p); // 释放空间
  }
  
  // 动态分配内存
  scanf("%d",&n);
  int *p = (int *)malloc(n*sizeof(int));
  ```

- 注意事项：

  - 检查内存分配结果是否为NULL，否则会有`空指针解引用`
  - 计算分配时使用`sizeof`，`malloc()`使用时初始化
  - `malloc()`分配后再次`malloc()`分配之前需要`free()`释放
  - 越界访问会破坏内存
  - `free()`释放指针后需要指针置空，避免重复释放
  - 函数中的内存分配需要明确内存由谁释放

- 段的区分：

  - 概念：`“段”就是把程序在内存中划分为几个逻辑区域;`如：代码段（TS）、初始化段(DS)、未初始化段(BSS)、堆段(HS)、栈段(SS)、常量区段(CS)
  - 作用：`内存保护，访问权限的不同，方便加载和初始化，提高效率`

  ```C
  #include <stdio.h>
  #include <stdlib.h>
  
  int g1 = 10;        // 已初始化的全局变量 -> 数据段（Data Segment）
  int g2;             // 未初始化的全局变量 -> BSS 段
  
  int main() {
      int a = 5;      // 局部变量 -> 栈段（Stack）
      static int s = 20; // 静态变量（已初始化） -> 数据段
      static int t;   // 静态变量（未初始化） -> BSS 段
      char *p = malloc(10); // 动态内存 -> 堆段（Heap）
      printf("Hello World\n"); // 字符串常量 -> 常量区 / 代码段
      free(p);
      return 0;
  }
  
  ```

  ```SCSS
  ┌────────────────────────────┐ ← 低地址
  │  代码段 (Text)             │ → 函数、机器指令
  ├────────────────────────────┤
  │  已初始化数据段 (Data)     │ → g1, s
  ├────────────────────────────┤
  │  未初始化数据段 (BSS)      │ → g2, t
  ├────────────────────────────┤
  │  堆区 (Heap)               │ → malloc分配的p
  │      ↑ 向上增长
  ├────────────────────────────┤
  │  栈区 (Stack)              │ → 局部变量a
  │      ↓ 向下增长
  └────────────────────────────┘ ← 高地址
  
  ```

## 可变参数函数

```C
#include <stdarg.h>
#include <stdio.h>

// Variadic function to add numbers
// n表示参数个数
int getSum(int n, ...) {
    int sum = 0;
    va_list list; // 创建变量参数列表
    va_start(list, n); // 初始化参数列表

    for (int i = 0; i < n; i++)
        // 此处可以添加判定条件
        sum += va_arg(list, int); // 检索参数
    va_end(list); // 清理va_list,释放资源
    return sum;
}
int main() {
    // Variable number of arguments
    printf("1 + 2 = %d\n",
           getSum(2, 1, 2));

    printf("3 + 4 + 5 = %d\n",
           getSum(3, 3, 4, 5));

    printf("6 + 7 + 8 + 9 = %d",
           getSum(4, 6, 7, 8, 9));

    return 0;
}
```

# C语言中常见错误处理`<errno.h>`

### 常见的文件错误处理

`<errno.h>`：***\*错误\****是定义在***\*<errno.h>\****头文件，指示在 C 中函数调用期间发生的错误。当函数失败时，errno 变量会自动设置为特定的错误代码，这有助于识别遇到的错误类型。

常用错误处理函数：

| 函数              | 功能                                                 |
| ----------------- | ---------------------------------------------------- |
| `perror()`        | error错误代码的详细描述                              |
| `strerror(errno)` | 错误的详细描述                                       |
| `ferror()`        | 文件作业期间出现错误（文件权限），它将返回一个非零值 |
| `feof()`          | 检测文件单字符读取操作（文件权限）是否达到文件末尾   |
| `clearerr()`      | 清除文件打开和作业期间的潜在错误                     |
| `exit()`          | 程序退出操作，分别为：`EXIT_FAILURE/EXIT_SUCCESS`    |
| `signal()`        | 注册信号处理函数`signal.h`                           |

其他常见错误：***除以零、输入验证、文件打开错误、超出范围的数组访问等，这些可以使用if-else自定义***

```C
#include <errno.h> 
#include <stdio.h> 
// strerror(errno) 将错误代码转为文字描述
#include <string.h> 

int main(){ 
    FILE* fp; 

    // Try opening a non-existent file, which sets errno
    fp = fopen("gfg.txt", "r"); 

    // Print the errno value after failed file opening
    printf("Value of errno: %d\n", errno); // errno 表示错误代码
    printf("The error message is: %s",strerror(errno)); // error 的详细文字描述
    perror("Message from perror"); // 错误代码的详细描述
    return 0; 
}
```

```C
#include <stdio.h>

int main() {
    FILE *fptr = fopen("gfg.txt", "w");
	if(fptr==NULL){
        perror("error")
    }
    // Write data to the file
    fprintf(fptr, "Hello, GFG!");
    
  	// Check error after writing data into file
    // 发生错误时（一般与权限有关系，并不代表fptr==NULL） ferror会返回非零值,通常为1
    if(!ferror(fptr))
        printf("Data written successfully.");
    else
        perror("unknown error")
    fclose(fptr);
    return 0;
}
```

### 信号处理函数使用

**信号是当用户按 Ctrl-C 或另一个进程向该进程发送信号时，作业系统向进程发送的软件生成的中断。有一组固定的信号可以发送到进程。信号由整数值标识**

部分信号类型：

| 信号名称  | 数值（不同系统略有不同） | 含义                                     |
| --------- | ------------------------ | ---------------------------------------- |
| `SIGINT`  | 2                        | 程序中断信号（通常是按 `Ctrl + C` 产生） |
| `SIGTERM` | 15                       | 程序终止信号（kill命令默认发送）         |
| `SIGABRT` | 6                        | 程序异常中止（如调用 `abort()`）         |
| `SIGSEGV` | 11                       | 段错误（访问非法内存-已释放的指针）      |
| `SIGFPE`  | 8                        | 算术错误（如除以零）                     |
| `SIGILL`  | 4                        | 非法指令                                 |
| `SIGALRM` | 14                       | 由 `alarm()` 函数触发的定时信号          |

```C
#include <stdio.h>
#include <signal.h>
#include <unistd.h>

void sigint_handler(int signum) {
    printf("\n收到信号 %d (SIGINT)，程序不会退出。\n", signum);
}

int main() {
    // 注册信号处理函数 SIGINT表示常见的信号
    signal(SIGINT, sigint_handler);

    while (1) {
        printf("程序运行中... 按 Ctrl + C 测试信号捕获\n");
        sleep(2);
    }

    return 0;
}
```

`raise()`函数使您能够向当前进程发送信号。它将信号类型作为参数，并在同一进程中触发该信号

```C
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>

// Signal handler function
void signalHandler(int sig) {
    printf("Interrupt handled: %d", sig);
    exit(sig);
}

int main() {
    signal(SIGINT, signalHandler);
    raise(SIGINT); // 向当前进程发送程序中断信号
    printf("Unable to output the modified content");
    return 0;
}
```

`kill()` 函数允许我们使用进程 id 将信号发送到其他进程或进程组

```C
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>
#include <unistd.h>

void handle_signal(int signal_num) {
    printf("Received signal: %d\n", signal_num);
}

int main() {
    
    // Handle signal
    signal(SIGINT, handle_signal);

    // Get current process ID
    pid_t pid = getpid();

    // Generate signal using kill()
    kill(pid, SIGINT); // pid 进程的ID
    return 0;
}
```
