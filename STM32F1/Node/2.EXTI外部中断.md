# STM32F103C8T6 EXTI 外部中断

本文从 STM32F103C8T6 的 GPIO 外部中断出发，介绍 EXTI 线路、GPIO 映射、触发方式、NVIC 配置和 EC11 编码器应用。示例使用 STM32F1 标准外设库。

## 一、EXTI 基本概念

EXTI（External Interrupt/Event Controller）是外部中断/事件控制器，用于检测外部引脚或芯片内部专用信号的边沿变化。当有效边沿到来时，EXTI 置位挂起标志；如果 EXTI 中断使能且 NVIC 通道允许，CPU 就会进入对应的中断服务函数。

STM32F1 常见 EXTI 线路如下，具体资源应以 STM32F103C8T6 数据手册和参考手册为准：

| EXTI 线路 | 典型来源 |
| --- | --- |
| EXTI0~EXTI15 | GPIO 引脚编号 0~15 |
| EXTI16 | PVD 电压监测 |
| EXTI17 | RTC 闹钟 |
| EXTI18 | USB 唤醒 |

EXTI0~EXTI15 按引脚编号分配，而不是按 GPIO 端口分配。例如 PA0、PB0、PC0 都对应 EXTI0，但同一时刻只能选择其中一个端口映射到 EXTI0。

## 二、EXTI 中断处理链路

```text
GPIO 输入边沿
    -> AFIO 将 GPIO 端口映射到 EXTI 线路
    -> EXTI 检测上升沿或下降沿
    -> EXTI 设置挂起标志
    -> EXTI 中断使能 + NVIC 通道使能
    -> CPU 进入 EXTI Handler
    -> 判断线路、处理事件、清除挂起标志
```

EXTI 只负责检测线路和产生请求，真正的优先级管理由 NVIC 完成。配置时需要同时完成 GPIO、AFIO、EXTI 和 NVIC 四部分。

## 三、EC11 增量式编码器

EC11 通常包含三根信号：

- A 相（CLK）：输出第一路脉冲；
- B 相（DT）：输出第二路脉冲，与 A 相相差约 90 度；
- C 相（SW）：按键输出，按下时通常接地。

A、B 两相构成正交编码信号，通过判断 A 相边沿发生时 B 相的电平，可以判断旋转方向。完整初始化和 Handler 代码见上面的配置示例。

机械编码器可能产生抖动，导致一次旋转产生多次响应。可以采用硬件 RC 滤波、施密特触发器，或在定时器周期任务中进行软件消抖。高速编码器更适合使用 TIM 的编码器接口，而不是完全依赖 EXTI。

## 四、EXTI 配置与 EC11 编码器示例

下面将 GPIO、AFIO、EXTI、NVIC 和中断服务函数放在同一个代码块中。示例使用 GPIOB 的 PB0 作为 A 相、PB1 作为 B 相，A 相双边沿触发 EXTI0。

```C
#include "stm32f10x.h" // Device header

volatile int16_t encoderCount;
static uint8_t lastA;

void encoder_init(void)
{
    // 1. 时钟使能：GPIOB 和 AFIO 都挂载在 APB2
    RCC_APB2PeriphClockCmd(
        RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE);

    // 2. GPIO 初始化：A 相 PB0、B 相 PB1 使用上拉输入
    GPIO_InitTypeDef GPIO_initstruct;
    GPIO_initstruct.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_initstruct.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1;
    GPIO_initstruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_initstruct);

    // 读取上电后的实际 A 相状态，避免第一次边沿被误判
    lastA = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_0);

    // 3. AFIO 映射：将 PB0 映射到 EXTI0
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource0);

    // 4. EXTI 初始化：A 相上升沿和下降沿均产生中断
    EXTI_InitTypeDef EXTI_InitStructure;
    EXTI_InitStructure.EXTI_Line = EXTI_Line0;
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Rising_Falling;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);

    // 5. NVIC 优先级配置：优先级分组整个芯片统一设置一次
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitTypeDef NVIC_InitStructure;
    NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

// 6. 中断服务函数：EXTI0 对应 A 相
void EXTI0_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line0) != RESET)
    {
        uint8_t currentA = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_0);
        uint8_t currentB = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1);

        if (lastA == 0 && currentA == 1)
        {
            encoderCount += (currentB == 0) ? 1 : -1;
        }
        else if (lastA == 1 && currentA == 0)
        {
            encoderCount += (currentB == 1) ? 1 : -1;
        }

        lastA = currentA;
        EXTI_ClearITPendingBit(EXTI_Line0); // 清除中断标志
    }
}

int16_t encoder_get(void)
{
    // A 相上升沿和下降沿均触发，每个定位约计数两次
    return encoderCount / 2;
}
```

EXTI 的 IRQ 通道分组如下：EXTI0~EXTI4 各有独立 Handler，EXTI5~EXTI9 共用 `EXTI9_5_IRQHandler`，EXTI10~EXTI15 共用 `EXTI15_10_IRQHandler`。共用 Handler 中必须逐个判断线路的挂起状态。

常用函数：

- `EXTI_GetITStatus()`：查询指定线路的中断状态；
- `EXTI_ClearITPendingBit()`：清除指定线路的挂起标志；
- `EXTI_GetFlagStatus()`：查询线路标志；
- `EXTI_ClearFlag()`：清除线路标志。

## 五、常见问题

1. **Handler 不执行**：检查 GPIO 和 AFIO 时钟、端口映射、EXTI 线路使能、NVIC 通道和全局中断。
2. **反复进入 Handler**：检查是否清除了正确的 EXTI 挂起标志。
3. **同一编号的 GPIO 无法同时使用**：PA0、PB0、PC0 共用 EXTI0，必须选择一个端口映射。
4. **按键一次触发多次**：这是机械抖动，需要硬件或软件消抖。
5. **Handler 执行太久**：中断中只采集事件或置位标志，复杂处理放到主循环。
