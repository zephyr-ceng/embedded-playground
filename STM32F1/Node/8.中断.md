# STM32F103C8T6 中断

本文以 STM32F103C8T6、Cortex-M3 内核和标准外设库为例，按照“概念 -> 分类 -> 配置 -> 应用”的顺序介绍中断。HAL 库的函数名称不同，但硬件链路和配置思想相同。

## 一、什么是中断

中断是硬件或内核通知 CPU 处理事件的一种机制。主程序正常运行时，如果按键产生边沿、定时器溢出、串口收到数据，CPU 会暂时保存当前执行现场，跳转到对应的中断服务函数（Handler），处理完成后再返回主程序。

**中断不等于定时器。** 中断是一套“事件通知 CPU”的机制，定时器只是能够产生中断请求的众多外设之一。EXTI、USART、DMA、ADC、SPI、I2C 等外设也都可以产生中断。定时器中断主要用于周期更新、输入捕获、输出比较和 PWM 等时间相关任务；是否进入中断，还要同时满足外设标志位置位、外设中断源使能和 NVIC 通道使能。

```text
事件发生
    -> 外设设置标志位
    -> 外设中断源使能
    -> NVIC 通道允许且优先级满足
    -> CPU 进入向量表指定的 Handler
    -> 判断标志、处理事件、清除标志
    -> 返回主程序
```

一条完整中断链路包含：

1. **事件源**：GPIO 边沿、计数溢出、数据接收等。
2. **外设标志位**：记录事件已经发生。
3. **外设中断使能位**：允许指定事件向 NVIC 发出请求。
4. **NVIC**：管理 IRQ 通道、优先级和嵌套。
5. **中断向量表**：把 IRQ 通道映射到 Handler。
6. **Handler**：判断来源、快速处理并清除标志。

### 1. 中断和轮询

轮询是在主循环中反复查询标志位；中断则由硬件在事件发生后主动通知 CPU。低频且必须按顺序执行的任务可以使用轮询；按键边沿、定时任务、串口接收和脉冲测量更适合中断。大量连续数据搬运通常使用 DMA，DMA 完成后再用中断通知软件。

### 2.各类型中断的配置与计算

#### 通用配置顺序

任何外设中断都可以按以下顺序排查和配置：

1. 打开外设和 GPIO 所在总线的时钟；
2. 配置 GPIO、外设功能和工作参数；
3. 清除初始化过程中可能产生的旧标志；
4. 设置 NVIC 优先级分组、IRQ 通道和优先级；
5. 打开外设内部的具体中断源；
6. 最后启动外设。

```C
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = TIM2_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 1;
nvic_config.NVIC_IRQChannelSubPriority = 0;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

TIM_ClearFlag(TIM2, TIM_FLAG_Update);
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
TIM_Cmd(TIM2, ENABLE);
```

#### NVIC 优先级配置

STM32F1 标准库使用 `NVIC_PriorityGroupConfig()` 分配抢占优先级和子优先级：

| 分组 | 抢占位数 | 子优先级位数 |
| --- | ---: | ---: |
| `NVIC_PriorityGroup_0` | 0 | 4 |
| `NVIC_PriorityGroup_1` | 1 | 3 |
| `NVIC_PriorityGroup_2` | 2 | 2 |
| `NVIC_PriorityGroup_3` | 3 | 1 |
| `NVIC_PriorityGroup_4` | 4 | 0 |

抢占优先级数值越小，优先级越高；子优先级只在抢占优先级相同的等待中断之间排序。一个工程应统一设置优先级分组。


#### 事件、标志和中断请求

| 名称 | 含义 | 例子 |
| --- | --- | --- |
| 事件 | 硬件实际发生的情况 | 定时器更新、USART 收到字节 |
| 标志位 | 外设对事件的记录 | 更新标志、`RXNE`、捕获标志 |
| 中断请求 | 外设送往 NVIC 的请求 | `TIM2_IRQn`、`USART1_IRQn` |

事件发生并不一定会进入 Handler。通常还必须打开外设中断源、NVIC 通道和全局中断，并且当前优先级允许响应。

### 4. 中断服务函数原则

- 先判断具体标志位，一个 IRQ 可能包含多个中断源；
- 快速读取数据、保存时间戳或设置软件标志；
- 使用该外设规定的方式清除标志；
- 不在中断中长延时、打印、动态分配内存或执行复杂协议解析；
- 与主程序共享的变量通常声明为 `volatile`；
- 共享多字节数据时还要考虑原子性和临界区。

```C
volatile uint8_t timer_update_flag = 0;

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET)
    {
        timer_update_flag = 1;
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

## 二、STM32 中的中断类型

STM32 的中断首先按来源分为内核异常和外设中断。可以按照硬件来源和功能整理如下：

以下表格以 STM32F103C8T6 为例；不同容量和封装的 STM32F1 型号，定时器资源可能有所不同。

| 中断大类 | 子类或相关模块 | 主要功能 | 中断请求关系 |
| --- | --- | --- | --- |
| 内核异常 | Reset、NMI、HardFault、SysTick、SVC、PendSV 等 | 处理复位、系统节拍、故障和内核服务 | 由 Cortex-M3 内核直接产生，不属于片上外设中断 |
| TIM 定时器中断 | 基本定时器（TIM6、TIM7；STM32F103C8T6 通常不具备） | 计数、周期更新、DAC 触发 | 由 TIM 更新事件通过对应 TIM IRQ 进入 Handler |
| TIM 定时器中断 | 通用定时器（TIM2、TIM3、TIM4） | 更新、输入捕获、输出比较、PWM、编码器和外部时钟计数 | 由 TIM 的更新、捕获、比较或触发标志请求中断 |
| TIM 定时器中断 | 高级定时器（TIM1） | 通用定时器功能、互补 PWM、死区、刹车和重复计数 | 由 TIM1 的更新、捕获、比较、刹车等 IRQ 通道请求中断 |
| TIM 的外部输入源 | ETR、TIx、ITRx | ETR 用于外部时钟/触发，TIx 用于捕获/编码器，ITRx 用于定时器同步 | 不是独立的 NVIC 中断；先影响 TIM 计数或触发控制器，再由 TIM 事件产生中断 |
| 其他外设中断 | EXTI、USART、DMA、ADC、SPI、I2C 等 | 分别处理 GPIO 边沿、数据状态、传输状态、转换和总线事件 | 与 TIM 并列，由各自外设 IRQ 通道请求中断 |

上表是分类索引，后文分别介绍各类中断的配置和应用。

### 1. 内核异常

内核异常由 Cortex-M3 产生，不依赖某一个外设：

| 异常 | 作用或典型原因 |
| --- | --- |
| Reset | 上电、复位或系统重启后的启动入口 |
| NMI | 不可屏蔽的紧急异常 |
| HardFault | 非法访问、栈错误、总线错误等严重故障 |
| MemManage、BusFault、UsageFault | 内存、总线和指令使用错误 |
| SVC | 系统服务调用 |
| PendSV | RTOS 任务切换 |
| SysTick | 系统节拍，常用于 1 ms 时基 |

常见函数是 `SysTick_Handler()` 和 `HardFault_Handler()`。HardFault 通常应回溯故障原因，而不是当作普通业务中断处理。

### 2. EXTI 外部中断

#### 基本概念

EXTI 用于检测外部输入线路的上升沿、下降沿或双边沿。STM32F1 中，EXTI0~EXTI15 按引脚编号对应 GPIO 线路，但同一条线路同一时间只能映射到一个端口。例如 PA0、PB0、PC0 都可以映射到 EXTI0，但不能同时使用。

常见线路如下，具体资源仍以 STM32F103C8T6 数据手册为准：

| 线路 | 来源 |
| --- | --- |
| EXTI0~EXTI15 | GPIO 外部输入 |
| EXTI16 | PVD 输出 |
| EXTI17 | RTC 闹钟 |
| EXTI18 | USB 唤醒 |

EXTI0~EXTI4 各有独立 Handler；EXTI5~EXTI9 共用 `EXTI9_5_IRQHandler()`；EXTI10~EXTI15 共用 `EXTI15_10_IRQHandler()`。

#### EXTI 外部中断配置

EXTI 配置需要 GPIO、AFIO 映射、EXTI 触发方式和 NVIC 四部分共同完成：

```C
RCC_APB2PeriphClockCmd(
    RCC_APB2Periph_GPIOA | RCC_APB2Periph_AFIO, ENABLE);

GPIO_InitTypeDef gpio_config = {0};
gpio_config.GPIO_Pin = GPIO_Pin_0;
gpio_config.GPIO_Mode = GPIO_Mode_IPU;
gpio_config.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &gpio_config);

GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0);

EXTI_InitTypeDef exti_config = {0};
exti_config.EXTI_Line = EXTI_Line0;
exti_config.EXTI_Mode = EXTI_Mode_Interrupt;
exti_config.EXTI_Trigger = EXTI_Trigger_Falling;
exti_config.EXTI_LineCmd = ENABLE;
EXTI_Init(&exti_config);

NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = EXTI0_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 2;
nvic_config.NVIC_IRQChannelSubPriority = 0;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

void EXTI0_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line0) != RESET)
    {
        key_event = 1;
        EXTI_ClearITPendingBit(EXTI_Line0);
    }
}
```

按键存在机械抖动，建议在 Handler 中记录事件，在主循环或定时器任务中消抖，不要在 Handler 中 `Delay_ms()`。


### 3. TIM 定时器中断

定时器可在更新、输入捕获、输出比较、触发等事件发生时产生中断。ETR（External Trigger，外部触发输入）是定时器的外部时钟或触发输入，不是独立的 NVIC 中断类型；ETR 的边沿驱动 CNT 或触发控制器后，定时器可以进一步产生更新中断或触发中断。STM32F103C8T6 常用资源可以这样理解：

| 定时器 | 类型 | 总线 | 主要能力 |
| --- | --- | --- | --- |
| TIM1 | 高级定时器 | APB2 | 基本计数、输入捕获、输出比较、PWM、互补输出、死区、刹车、重复计数器 |
| TIM2~TIM4 | 通用定时器 | APB1 | 基本计数、输入捕获、输出比较、PWM、编码器、外部时钟、主从触发 |
| TIM6、TIM7 | 基本定时器 | APB1 | 部分 STM32F1 型号具有基本定时和 DAC 触发能力；STM32F103C8T6 通常不具备，必须核对启动文件和数据手册 |


#### 3.1 基本定时器中断

基本定时器只有内部时钟计数和更新事件能力，适合周期性任务、DAC 触发和软件时基。它没有 GPIO 通道，因此不能直接做 PWM、输入捕获或输出比较。

**基本定时器：周期任务**

基本定时的目标是让硬件以固定周期产生更新事件。例如 `f_TIM = 72 MHz`，设置 `PSC = 7199`、`ARR = 9999`，则：

$$f_{CNT}=\frac{72\text{ MHz}}{7200}=10\text{ kHz}$$

$$f_{update}=\frac{10\text{ kHz}}{10000}=1\text{ Hz}$$

这时 Handler 每秒执行一次。实际项目中可以让 Handler 只增加计数或置位，再在主循环处理 LED、按键扫描和状态机。

**基本定时器：更新中断配置**

```C
#include "stm32f10x.h"

volatile uint32_t timer_tick = 0;

void TIM4_TimeBase_Init(void)
{
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM4, ENABLE);

    TIM_TimeBaseInitTypeDef timebase_config = {0};
    timebase_config.TIM_Prescaler = 7200 - 1;
    timebase_config.TIM_Period = 10000 - 1;
    timebase_config.TIM_ClockDivision = TIM_CKD_DIV1;
    timebase_config.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM4, &timebase_config);

    NVIC_InitTypeDef nvic_config = {0};
    nvic_config.NVIC_IRQChannel = TIM4_IRQn;
    nvic_config.NVIC_IRQChannelPreemptionPriority = 1;
    nvic_config.NVIC_IRQChannelSubPriority = 0;
    nvic_config.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&nvic_config);

    TIM_ClearFlag(TIM4, TIM_FLAG_Update);
    TIM_ITConfig(TIM4, TIM_IT_Update, ENABLE);
    TIM_Cmd(TIM4, ENABLE);
}

void TIM4_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM4, TIM_IT_Update) != RESET)
    {
        timer_tick++;
        TIM_ClearITPendingBit(TIM4, TIM_IT_Update);
    }
}
```

#### 3.2 通用定时器中断

通用定时器在基本计数基础上增加 TIx 输入、ETR 外部触发输入以及 CH1~CH4 通道，可以完成输入捕获、输出比较、PWM 和编码器接口。

**通用定时器：PWM 输出**

PWM 是定时器输出比较单元在每个周期内改变引脚电平形成的脉冲信号。PWM 频率和占空比常用计算式为：

$$f_{PWM}=\frac{f_{TIM}}{(PSC+1)(ARR+1)}$$

$$Duty=\frac{CCR}{ARR+1}\times100\%$$

例如 `f_TIM = 72 MHz`，需要 20 kHz PWM：取 `PSC = 71`，则计数频率为 1 MHz，`ARR = 49`；设置 `CCR = 25` 时，占空比约为 50%。

标准外设库以 TIM2_CH1（PA0 默认映射）为例：

```C
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

GPIO_InitTypeDef gpio_config = {0};
gpio_config.GPIO_Pin = GPIO_Pin_0;
gpio_config.GPIO_Mode = GPIO_Mode_AF_PP;
gpio_config.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &gpio_config);

TIM_TimeBaseInitTypeDef timebase_config = {0};
timebase_config.TIM_Prescaler = 72 - 1;
timebase_config.TIM_Period = 50 - 1;
timebase_config.TIM_CounterMode = TIM_CounterMode_Up;
timebase_config.TIM_ClockDivision = TIM_CKD_DIV1;
TIM_TimeBaseInit(TIM2, &timebase_config);

TIM_OCInitTypeDef output_config = {0};
output_config.TIM_OCMode = TIM_OCMode_PWM1;
output_config.TIM_OutputState = TIM_OutputState_Enable;
output_config.TIM_OCPolarity = TIM_OCPolarity_High;
output_config.TIM_Pulse = 25;
TIM_OC1Init(TIM2, &output_config);
TIM_OC1PreloadConfig(TIM2, TIM_OCPreload_Enable);
TIM_ARRPreloadConfig(TIM2, ENABLE);
TIM_Cmd(TIM2, ENABLE);
```

修改占空比时只需要修改 CCR：

```C
void TIM2_PWM_SetDuty(uint16_t compare_value)
{
    if (compare_value > 50)
        compare_value = 50;

    TIM_SetCompare1(TIM2, compare_value);
}
```

PWM 输出通常不需要每个周期都进入中断；只有需要在更新点同步修改参数时，才打开更新中断。普通 PWM 主要使用 TIM2~TIM4 的通用定时器通道。


**通用定时器：输入捕获**

输入捕获在检测到指定边沿时，把当前 CNT 自动复制到 CCR。若计数频率为 1 MHz，则一个计数单位是 1 us。连续捕获两个上升沿：

$$T_{signal}=\frac{Capture_2-Capture_1}{f_{CNT}}$$

$$f_{signal}=\frac{f_{CNT}}{Capture_2-Capture_1}$$

测量高电平脉宽时，捕获上升沿记录起点，再捕获下降沿记录终点；配置时要处理计数器溢出。输入捕获常用 `TIM_IT_CC1` 等捕获比较中断，Handler 中使用 `TIM_GetCapture1()` 读取捕获值。

下面示例把 TIM3_CH1（PA6）配置为上升沿输入捕获，并将计数频率设置为 1 MHz：

```C
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

GPIO_InitTypeDef gpio_config = {0};
gpio_config.GPIO_Pin = GPIO_Pin_6;
gpio_config.GPIO_Mode = GPIO_Mode_IN_FLOATING;
gpio_config.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &gpio_config);

TIM_TimeBaseInitTypeDef timebase_config = {0};
timebase_config.TIM_Prescaler = 72 - 1;
timebase_config.TIM_Period = 65535;
timebase_config.TIM_CounterMode = TIM_CounterMode_Up;
timebase_config.TIM_ClockDivision = TIM_CKD_DIV1;
TIM_TimeBaseInit(TIM3, &timebase_config);

TIM_ICInitTypeDef input_config = {0};
input_config.TIM_Channel = TIM_Channel_1;
input_config.TIM_ICPolarity = TIM_ICPolarity_Rising;
input_config.TIM_ICSelection = TIM_ICSelection_DirectTI;
input_config.TIM_ICPrescaler = TIM_ICPSC_DIV1;
input_config.TIM_ICFilter = 4;
TIM_ICInit(TIM3, &input_config);

NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = TIM3_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 1;
nvic_config.NVIC_IRQChannelSubPriority = 1;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

TIM_ITConfig(TIM3, TIM_IT_CC1, ENABLE);
TIM_Cmd(TIM3, ENABLE);
```

```C
volatile uint16_t capture_value = 0;
volatile uint8_t capture_ready = 0;

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_CC1) != RESET)
    {
        capture_value = TIM_GetCapture1(TIM3);
        capture_ready = 1;
        TIM_ClearITPendingBit(TIM3, TIM_IT_CC1);
    }
}
```

输入捕获配置的关键参数是通道、直接或间接输入映射、有效极性、输入预分频 `TIM_ICPrescaler` 和数字滤波 `TIM_ICFilter`。滤波值越大并不代表边沿越灵敏，而是需要更长的稳定采样时间；应根据信号频率和噪声调整。

**通用定时器：输出比较**

输出比较把 CNT 与 CCR 比较。当 CNT 等于 CCR 时，可以翻转、置位、清零通道输出，或者只产生比较中断。它与 PWM 的区别是：PWM 关注一个周期内的持续占空比，输出比较关注“计数到某个值时执行一次动作”。

```C
TIM_OCInitTypeDef output_config = {0};
output_config.TIM_OCMode = TIM_OCMode_Toggle;
output_config.TIM_OutputState = TIM_OutputState_Enable;
output_config.TIM_OCPolarity = TIM_OCPolarity_High;
output_config.TIM_Pulse = 1000;
TIM_OC1Init(TIM2, &output_config);
TIM_ITConfig(TIM2, TIM_IT_CC1, ENABLE);

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_CC1) != RESET)
    {
        TIM_ClearITPendingBit(TIM2, TIM_IT_CC1);
        TIM_SetCompare1(TIM2, TIM_GetCompare1(TIM2) + 1000);
    }
}
```

上例以 1 MHz 计数为前提，每次比较后把下一次比较点向后移动 1000 个计数，可生成周期性翻转信号。实际使用时要考虑 CCR 溢出和计数模式。


#### 3.3 高级定时器中断

高级定时器面向电机和功率控制，除通用定时器功能外，还增加互补 PWM、死区时间、刹车输入和重复计数器。使用 TIM1 的主输出时，还需要正确配置 `TIM_CtrlPWMOutputs(TIM1, ENABLE)`。

**高级定时器：互补 PWM、死区和刹车**

TIM1 在通用定时器 PWM 的基础上，可以输出主通道和互补通道，例如 `TIM1_CH1` 与 `TIM1_CH1N`，适合驱动半桥或三相逆变器。互补输出不能简单理解为“把两个 GPIO 电平取反”，它由定时器硬件根据极性、死区和刹车状态生成。

```C
TIM_OCInitTypeDef output_config = {0};
output_config.TIM_OCMode = TIM_OCMode_PWM1;
output_config.TIM_OutputState = TIM_OutputState_Enable;
output_config.TIM_OutputNState = TIM_OutputNState_Enable;
output_config.TIM_OCPolarity = TIM_OCPolarity_High;
output_config.TIM_OCNPolarity = TIM_OCNPolarity_High;
output_config.TIM_OCIdleState = TIM_OCIdleState_Reset;
output_config.TIM_OCNIdleState = TIM_OCNIdleState_Reset;
output_config.TIM_Pulse = 25;
TIM_OC1Init(TIM1, &output_config);

TIM_BDTRInitTypeDef break_config = {0};
break_config.TIM_OSSRState = TIM_OSSRState_Enable;
break_config.TIM_OSSIState = TIM_OSSIState_Enable;
break_config.TIM_LOCKLevel = TIM_LOCKLevel_OFF;
break_config.TIM_DeadTime = 10;
break_config.TIM_Break = TIM_Break_Disable;
break_config.TIM_BreakPolarity = TIM_BreakPolarity_High;
break_config.TIM_AutomaticOutput = TIM_AutomaticOutput_Enable;
TIM_BDTRConfig(TIM1, &break_config);

TIM_CtrlPWMOutputs(TIM1, ENABLE);
TIM_Cmd(TIM1, ENABLE);
```

死区时间用于防止上下桥臂同时导通。实际死区时间由定时器时钟和 `DeadTime` 编码共同决定，不能直接把该参数当作微秒数；功率器件应用必须结合参考手册和驱动器件计算。刹车输入触发后，TIM1 可以硬件关闭主输出，提升故障保护速度。


### 3.4 通用定时器和高级定时器：ETR 外部时钟、触发和更新中断

ETR 是定时器的外部触发输入，可作为外部时钟或触发源。它和 EXTI 的区别是：EXTI 直接向 NVIC 请求 GPIO 外部中断；ETR 先进入定时器内部，驱动 CNT 或触发控制器，之后由 TIM 的更新、触发等标志产生中断。

| 项目 | 外部时钟模式 1 | 外部时钟模式 2 |
| --- | --- | --- |
| 信号路径 | ETR -> TRGI -> 从模式控制器 -> CNT | ETR -> 外部时钟电路 -> CNT |
| 配置重点 | `TIM_SelectInputTrigger()`、`TIM_SelectSlaveMode()` | `TIM_ETRClockMode2Config()` |
| 适合场景 | 门控、复位、触发、与其他定时器同步 | 外部脉冲直接计数 |

常用配置函数如下：

```C
// 外部时钟模式 2：ETR 的有效边沿直接驱动 TIM1 CNT
TIM_ETRClockMode2Config(
    TIM1,
    TIM_ExtTRGPSC_OFF,
    TIM_ExtTRGPolarity_NonInverted,
    0x0F);

TIM_ITConfig(TIM1, TIM_IT_Update, ENABLE);
TIM_Cmd(TIM1, ENABLE);
```

外部时钟模式 1 需要先选择 ETR 为触发输入，再选择从模式。例如门控模式可以实现“ETR 为高电平时计数，低电平时暂停”：

```C
// 外部时钟模式 1：ETR -> TRGI -> 从模式控制器 -> CNT
TIM_ETRConfig(
    TIM1,
    TIM_ExtTRGPSC_OFF,
    TIM_ExtTRGPolarity_NonInverted,
    0x0F);
TIM_SelectInputTrigger(TIM1, TIM_TS_ETRF);
TIM_SelectSlaveMode(TIM1, TIM_SlaveMode_Gated);

TIM_ITConfig(TIM1, TIM_IT_Update, ENABLE);
TIM_Cmd(TIM1, ENABLE);
```

ETR 输入还可以设置外部触发预分频、极性和数字滤波。使用 TIM1 时应初始化 `TIM_RepetitionCounter`，并根据具体中断向量使用 `TIM1_UP_IRQn` 或芯片启动文件规定的通道。外部脉冲计数溢出时，可在更新中断中累加软件高位：

```C
volatile uint32_t etr_overflow = 0;

void TIM1_UP_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM1, TIM_IT_Update) != RESET)
    {
        etr_overflow++;
        TIM_ClearITPendingBit(TIM1, TIM_IT_Update);
    }
}
```

### 3.5 通用定时器和高级定时器：编码器接口

通用或高级定时器可以使用 TI1/TI2 两路正交信号判断旋转方向并累计 CNT。编码器模式本质上是输入捕获通道和从模式控制器的组合，通常不需要每个边沿都进入 CPU 中断，而是在固定周期读取 CNT 计算增量和速度。若需要处理溢出或异常，再开启更新或捕获中断。

### 3.6. 通用定时器和高级定时器：主从触发和同步采样

一个定时器可以通过 TRGO 输出更新事件或比较事件，另一个定时器通过 ITR 接收，形成同步计数、触发 ADC 或相位控制。同步 ADC 采样通常让定时器产生 TRGO，ADC 按外部触发启动转换，DMA 搬运采样结果，避免在每次采样中断中处理大量数据。

### 4. 其他外设中断

USART、DMA、ADC、SPI、I2C 等不是定时器的子类，而是独立外设。它们与 TIM 一样通过 NVIC 向 CPU 请求中断，后文将分别说明它们与定时器的配合方式。

#### 4.1 USART 中断

USART 常见中断源包括：

- `RXNE`：接收数据寄存器非空；
- `TXE`：发送数据寄存器为空；
- `TC`：最后一位数据发送完成；
- `IDLE`：检测到空闲线路，常与 DMA 接收不定长数据配合；
- 帧错误、噪声、溢出等错误中断。

USART 中断适合字节流接收和发送队列通知。接收数据应尽快读出并放入缓冲区，协议解析放到主循环或任务中。

#### 4.2 DMA 中断

DMA 在外设与存储器之间自动搬运数据。常见中断源有传输完成（TC）、半传输（HT）和传输错误（TE）。DMA 本身不是数据来源，而是减少 CPU 搬运工作的外设；USART、ADC、SPI 等外设可以触发 DMA 请求。

STM32F103C8T6 的 DMA 通道与外设请求有固定映射，使用前必须查参考手册。USART + DMA 接收不定长数据时，常见方案是 DMA 循环接收，USART `IDLE` 中断判断一帧结束，再根据 DMA 当前计数计算长度。

#### 4.3 ADC、SPI、I2C 等外设中断

- ADC：规则组转换完成 `EOC`、注入组转换完成 `JEOC`、模拟看门狗越限 `AWD`；
- SPI：接收缓冲区非空、发送缓冲区为空、错误状态；
- I2C：事件中断和错误中断，通常需要按状态寄存器状态机处理；
- RTC、看门狗、USB 等：具体线路和 IRQ 名称依芯片型号、容量和启动文件而定。

ADC 中断通常在规则组转换完成（`EOC`）时读取结果。ADC 的 GPIO 必须配置为模拟输入，ADC 时钟不能超过芯片规定上限；连续多通道采样更适合使用 ADC + DMA，而不是每个通道都进入 CPU 中断。

```C
RCC_APB2PeriphClockCmd(
    RCC_APB2Periph_GPIOA | RCC_APB2Periph_ADC1, ENABLE);

GPIO_InitTypeDef gpio_config = {0};
gpio_config.GPIO_Pin = GPIO_Pin_1;
gpio_config.GPIO_Mode = GPIO_Mode_AIN;
GPIO_Init(GPIOA, &gpio_config);

ADC_InitTypeDef adc_config = {0};
adc_config.ADC_Mode = ADC_Mode_Independent;
adc_config.ADC_ScanConvMode = DISABLE;
adc_config.ADC_ContinuousConvMode = DISABLE;
adc_config.ADC_ExternalTrigConv = ADC_ExternalTrigConv_None;
adc_config.ADC_DataAlign = ADC_DataAlign_Right;
adc_config.ADC_NbrOfChannel = 1;
ADC_Init(ADC1, &adc_config);

ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 1,
                         ADC_SampleTime_55Cycles5);
ADC_ITConfig(ADC1, ADC_IT_EOC, ENABLE);

NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = ADC1_2_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 2;
nvic_config.NVIC_IRQChannelSubPriority = 0;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

ADC_Cmd(ADC1, ENABLE);
ADC_ResetCalibration(ADC1);
while (ADC_GetResetCalibrationStatus(ADC1) != RESET);
ADC_StartCalibration(ADC1);
while (ADC_GetCalibrationStatus(ADC1) != RESET);
ADC_SoftwareStartConvCmd(ADC1, ENABLE);

void ADC1_2_IRQHandler(void)
{
    if (ADC_GetITStatus(ADC1, ADC_IT_EOC) != RESET)
    {
        adc_value = ADC_GetConversionValue(ADC1);
        ADC_ClearITPendingBit(ADC1, ADC_IT_EOC);
    }
}
```


### 6. USART 外设中断配置

USART1 使用 PA9/PA10 时，需要打开 GPIOA 和 USART1 的 APB2 时钟；USART2/3 的时钟和引脚属于其他总线。以接收中断为例：

```C
RCC_APB2PeriphClockCmd(
    RCC_APB2Periph_GPIOA | RCC_APB2Periph_USART1, ENABLE);

GPIO_InitTypeDef gpio_config = {0};
gpio_config.GPIO_Pin = GPIO_Pin_9;
gpio_config.GPIO_Mode = GPIO_Mode_AF_PP;
gpio_config.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &gpio_config);

gpio_config.GPIO_Pin = GPIO_Pin_10;
gpio_config.GPIO_Mode = GPIO_Mode_IN_FLOATING;
GPIO_Init(GPIOA, &gpio_config);

USART_InitTypeDef usart_config = {0};
usart_config.USART_BaudRate = 115200;
usart_config.USART_WordLength = USART_WordLength_8b;
usart_config.USART_StopBits = USART_StopBits_1;
usart_config.USART_Parity = USART_Parity_No;
usart_config.USART_HardwareFlowControl = USART_HardwareFlowControl_None;
usart_config.USART_Mode = USART_Mode_Rx | USART_Mode_Tx;
USART_Init(USART1, &usart_config);

NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = USART1_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 2;
nvic_config.NVIC_IRQChannelSubPriority = 0;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

USART_ITConfig(USART1, USART_IT_RXNE, ENABLE);
USART_Cmd(USART1, ENABLE);

void USART1_IRQHandler(void)
{
    if (USART_GetITStatus(USART1, USART_IT_RXNE) != RESET)
    {
        uint8_t received_byte = (uint8_t)USART_ReceiveData(USART1);
        RingBuffer_Put(received_byte);
    }
}
```

`RXNE` 通常通过读取数据寄存器处理；`IDLE` 通常按参考手册要求先读状态寄存器再读数据寄存器。不同 USART 标志的清除规则不能混用。

### 7. DMA 外设中断配置要点

DMA 配置必须明确源地址、目标地址、方向、数据宽度、传输数量、地址是否递增、普通或循环模式以及通道优先级。DMA 中断还要同时配置 DMA 控制器的 NVIC 通道和具体的 TC/HT/TE 中断源。

```C
DMA_ITConfig(DMA1_Channel5, DMA_IT_TC | DMA_IT_TE, ENABLE);

NVIC_InitTypeDef nvic_config = {0};
nvic_config.NVIC_IRQChannel = DMA1_Channel5_IRQn;
nvic_config.NVIC_IRQChannelPreemptionPriority = 1;
nvic_config.NVIC_IRQChannelSubPriority = 1;
nvic_config.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&nvic_config);

void DMA1_Channel5_IRQHandler(void)
{
    if (DMA_GetITStatus(DMA1_IT_TC5) != RESET)
    {
        dma_receive_done = 1;
        DMA_ClearITPendingBit(DMA1_IT_TC5);
    }

    if (DMA_GetITStatus(DMA1_IT_TE5) != RESET)
    {
        dma_receive_error = 1;
        DMA_ClearITPendingBit(DMA1_IT_TE5);
    }
}
```

实际通道号和外设请求的对应关系必须以 STM32F103C8T6 参考手册为准；上面的通道用于展示 Handler 结构。

## 四、常见问题与调试顺序

### 1. Handler 不执行

依次检查：事件是否发生、外设标志是否置位、外设中断源是否开启、NVIC 通道是否开启、IRQ 名称是否与启动文件一致、全局中断是否被关闭。

### 2. 反复进入同一个中断

通常是标志位没有清除，或清除顺序不符合该外设规定。USART `IDLE`、ADC、I2C 等标志尤其不能套用定时器的清除方式。

### 3. 定时周期不准确

检查系统时钟、APB 分频、定时器时钟倍频、PSC/ARR 是否忘记加 1，以及高级定时器重复计数器是否参与了更新事件。

### 4. PWM 频率正确但占空比不对

检查 `CCR` 是否在 `0 ~ ARR` 范围内、PWM 极性是否正确、GPIO 是否配置为复用推挽输出，以及 TIM1 是否开启主输出。

### 5. 输入捕获数值跳变

检查输入引脚映射、有效边沿、输入滤波、输入预分频和计数器溢出处理。机械触点或长线信号还需要硬件整形或软件消抖。

### 6. 中断中执行时间过长

把中断改为“采集数据、置位标志、退出”，将显示、打印、协议解析和耗时计算放到主循环或任务中。DMA 可以进一步减少高频数据的中断次数。

## 五、总结

STM32 中断的统一链路是：**事件 -> 外设标志 -> 外设中断使能 -> NVIC -> 向量表 -> Handler -> 清除标志**。EXTI 负责外部边沿，USART 和 ADC 负责数据状态，DMA 负责传输状态，TIM 负责周期、比较和捕获。定时器内部又分为基本、通用和高级三类，能力依次扩展。

学习和设计时，先确定事件来源和所需的时间精度，再选择轮询、中断或 DMA；对于 TIM，则先确定 `f_TIM`，再用 PSC、ARR 和 CCR 分别确定计数粒度、周期和占空比或比较时刻。
