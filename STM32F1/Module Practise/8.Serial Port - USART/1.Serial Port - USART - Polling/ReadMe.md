## 串口的轮询模式

### 1. **基础配置功能**

| 功能点            | 关键操作                                                     | 说明                                   |
| :---------------- | :----------------------------------------------------------- | :------------------------------------- |
| **GPIO初始化**    | `GPIO_Mode_AF_PP`(TX), `GPIO_Mode_IN_FLOATING`(RX)           | TX配置为复用推挽输出，RX配置为浮空输入 |
| **USART参数配置** | 设置波特率、数据位(8b)、停止位(1b)、校验位(No)、硬件流控(None) | 需与通信设备参数完全匹配               |
| **时钟使能**      | `RCC_APB2PeriphClockCmd()`(USART1), `RCC_APB2Periph_GPIOA`   | 必须使能USART和对应GPIO时钟            |

```c
typedef struct {
    uint32_t USART_BaudRate;            // 波特率 2400\9600\19200\115200
    uint16_t USART_WordLength;          // 字长
    uint16_t USART_StopBits;            // 停止位
    uint16_t USART_Parity;              // 校验位
    uint16_t USART_Mode;                // USART模式(USART_Mode_Rx | USART_Mode_Tx)
    uint16_t USART_HardwareFlowControl; // 硬件流控制
} USART_InitTypeDef;
```

### 2. **数据发送功能**

| 功能点         | 关键标志位/操作                                              | 特性                             |
| :------------- | :----------------------------------------------------------- | :------------------------------- |
| **单字节发送** | 轮询`USART_FLAG_TXE` → `USART_SendData()` → 轮询`USART_FLAG_TC` | 严格等待发送完成，保证数据完整性 |
| **字符串发送** | 循环调用单字节发送，自动处理`\0`结束符                       | 简单可靠但效率较低               |
| **阻塞机制**   | `while(USART_GetFlagStatus() == RESET)`                      | 确保每个字节完整传输             |

### 3. **数据接收功能**

| 功能点           | 关键实现                                      | 注意事项               |
| :--------------- | :-------------------------------------------- | :--------------------- |
| **单字节接收**   | 轮询`USART_FLAG_RXNE` → `USART_ReceiveData()` | 会阻塞程序直至收到数据 |
| **字符串接收**   | 循环接收+终止符(`\n`/`\r`)检测+缓冲区保护     | 需预分配足够缓冲区空间 |
| **基本错误防护** | `maxLength-1`限制防止溢出                     | 保证字符串以`\0`结尾   |

### 4. **关键状态标志位**

| 标志位            | 含义               | 典型应用场景           |
| :---------------- | :----------------- | :--------------------- |
| `USART_FLAG_TXE`  | 发送数据寄存器空   | 判断是否可以发送新数据 |
| `USART_FLAG_TC`   | 发送完成           | 确认数据已完全发出     |
| `USART_FLAG_RXNE` | 接收数据寄存器非空 | 判断是否有数据到达     |
