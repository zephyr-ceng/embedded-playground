# STM32F103 TIM1 TIx 外部时钟模式 1

## 项目目的

本项目使用 STM32F103 的 TIM1 TI1FP1 输入接收循迹检测模块的数字脉冲，通过外部时钟模式 1 计数。TI1FP1 作为触发源，经输入滤波器、触发器和从模式选择器连接到定时器计数器，并检测上升沿；计数器溢出后使用 TIM1 更新中断累计计数周期。OLED 显示内容和十一个有效脉冲产生一次更新事件的主流程保持不变。

## 关键配置

- 循迹检测模块输出：PA8 / TIM1_CH1 / TI1。
- TI1FP1 外部时钟模式：模式 1，使用输入滤波器和触发器-从模式选择器计数。
- 触发极性：上升沿有效（`TIM_ICPolarity_Rising`）。
- TI1FP1 输入滤波：0x0F。
- TIM1 预分频器：PSC = 0。
- TIM1 自动重装值：ARR = 10。
- TIM1 更新中断：TIM1_UP_IRQn。

定时器及循迹检测模块的触发配置统一位于 `src/drive/src/Timer.c`，接口位于 `src/drive/inc/Timer.h`。PA8/TI1 输入经过滤波形成 TI1FP1，每个有效上升沿驱动 TIM1 计数器递增；当计数器从 0 计数到 ARR（10）后，再接收 1 个脉冲产生更新事件，溢出次数由 `Get_Overflow_value()` 提供。总脉冲数按 `溢出次数 * 11 + 当前计数器值` 计算。

## TIx 与 ITRx 扩展

`TIM_TIxExternalClockConfig()` 可选择 `TI1F_ED`、`TI1FP1` 或 `TI2FP2` 作为外部时钟源。本项目选择 `TI1FP1`：输入引脚为 `PA8 / TIM1_CH1 / TI1`，经过数字滤波后检测上升沿。输入滤波值范围为 `0x00~0x0F`。

如果时钟来自其他定时器的 `TRGO`，可使用 `TIM_ITRxExternalClockConfig()` 选择 `TIM_TS_ITR0` 到 `TIM_TS_ITR3`。ITR0~ITR3 的具体定时器映射由芯片参考手册决定，此时不需要 TI1/TI2 外部引脚。

## 硬件要求

### 循迹检测模块

本项目使用带有一个可调节螺丝的红外循迹检测模块。调节该螺丝可以改变模块的检测灵敏度或数字输出翻转阈值；上电后应根据实际循迹信号调节，确保 `D0` 能稳定输出高、低电平。

模块引脚如下：

| 模块引脚 | 作用 | 本项目接法 |
| --- | --- | --- |
| `A0` | 模拟输出 | 不接 |
| `D0` | 数字输出 | 接 `PA8 / TIM1_CH1 / TI1` |
| `GND` | 电源地 | 接 STM32 `GND` |
| `VDD` | 电源正极 | 接与模块额定电压匹配的电源 |

接线示意图：

```text
循迹检测模块                         STM32F103
┌─────────────────┐                 ┌──────────────────┐
│ A0  模拟输出    │       不接      │                  │
│ D0  数字输出    ├────────────────>│ PA8 / TIM1_CH1/TI1│
│ GND 电源地      ├────────────────>│ GND              │
│ VDD 电源正极    ├────────────────>│ 3.3V 或额定电源  │
│                 │                 │                  │
│   可调节螺丝    │                 └──────────────────┘
└─────────────────┘
```

1. 循迹模块输出必须是 STM32F103 可接受的数字电平。
2. 循迹模块与 STM32 必须共地。
3. PA8 同时是 TIM1_CH1/TI1，使用 TI1 时不要让其他外部电路占用该引脚。
4. 当前配置使用上升沿计数；若模块输出极性相反，需要调整 TI1 极性或模块输出。

## 构建与下载

本项目使用 VS Code Embedded IDE 工程配置，提供以下任务：

- `build`：编译工程。
- `rebuild`：清理后重新编译。
- `flash`：下载程序到目标芯片。
- `build and flash`：编译并下载。
