# EXTI_EC11

基于 STM32F103C8T6、STM32 HAL 和 CMake 的 EC11 旋转编码器练习项目。程序使用 GPIO 外部中断读取 EC11 的 A/B 两相，按正交编码判断旋转方向，并在 OLED 上显示累计值。

## 硬件与引脚

| 功能 | STM32 引脚 | 配置/说明 |
| --- | --- | --- |
| EC11 A 相 | PB0 / EXTI0 | 上拉输入，双边沿触发 |
| EC11 B 相 | PB1 / EXTI1 | 上拉输入，双边沿触发 |
| OLED SCL | PB11 | OLED 时钟线 |
| OLED SDA | PB12 | OLED 数据线 |
| EC11 公共端 | GND | A、B 相需有合适的上拉；本项目启用 MCU 内部上拉 |

EC11 和 OLED 与开发板需共地，且输入电压不得超过 MCU 允许范围。OLED 用于显示当前计数值，接线按上表连接即可。

## EXTI 配置

`MX_GPIO_Init()` 中的配置如下：

1. 使能 GPIOB 时钟。
2. PB0 和 PB1 均配置为 `GPIO_MODE_IT_RISING_FALLING`，即上升沿、下降沿都会触发中断。
3. 两相均启用内部上拉（`GPIO_PULLUP`）。对于常见公共端接 GND 的机械式 EC11，触点闭合时读低电平、断开时由上拉保持高电平。
4. 使能 `EXTI0_IRQn` 与 `EXTI1_IRQn`，优先级设置为 0。
5. `Core/Src/stm32f1xx_it.c` 中的 `EXTI0_IRQHandler()`、`EXTI1_IRQHandler()` 分别调用 `HAL_GPIO_EXTI_IRQHandler()`；HAL 随后调用 `HAL_GPIO_EXTI_Callback()`，应用在该回调中完成正交解码。


## EC11 正反转检测逻辑

### AB 两相信号的触发原理

EC11 内部的两路触点在转动时依次接通、断开，产生 A、B 两相信号。两相不是同时变化，而是相差约 **90°电角度**（四分之一周期）。因此，旋转时一相会先变化，另一相随后变化；反向旋转时，先后顺序反过来。程序就是通过判断这个先后关系确定方向。

PB0 连接 A 相，PB1 连接 B 相；两路均配置为上升沿、下降沿触发。每当任一相发生边沿，HAL 就调用 `HAL_GPIO_EXTI_Callback(GPIO_Pin)`。回调读取此时 A、B 的电平并组合成状态：A 为高位、B 为低位。

例如一种方向的状态序列为：

| 状态变化 | 触发边沿 | 另一相电平 | 含义 |
| --- | --- | --- | --- |
| `00 → 01` | B 上升沿 | A=0 | B 先变化 |
| `01 → 11` | A 上升沿 | B=1 | A 随后变化 |
| `11 → 10` | B 下降沿 | A=1 | B 再次变化 |
| `10 → 00` | A 下降沿 | B=0 | 完成一周期 |

反向转动时，同一组状态按相反顺序经过：`00 → 10 → 11 → 01 → 00`。实际哪一个方向称为顺时针，取决于 A/B 接线及观察方向；若显示的正负与预期相反，可以交换 A/B 接线。

### 为什么一个完整周期累计为 4

在上面的一个完整周期中，B 相经历一次上升沿和一次下降沿，A 相也经历一次上升沿和一次下降沿。由于 A、B 都设置为双边沿中断，这四个边沿分别触发四次 EXTI。每次回调将新旧状态查表，得到一个方向步进（`+1` 或 `-1`）；累计四次有效状态变化后，才将计数加一或减一。

因此代码中的 `EC11_QuarterSteps` 表示**相对于一个完整 AB 正交电周期的四分之一步进数**：一次相邻状态变化是四分之一周期，四次变化组成完整周期。它不是说 A 相的一整次上升沿加下降沿只算四分之一，也不保证对应旋钮的一个机械定位格；每个定位格对应多少电气变化取决于具体 EC11 型号。
