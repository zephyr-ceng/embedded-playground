| **STM32外设功能**   | **对应典型模块**                                    |
| ------------------- | --------------------------------------------------- |
| **ADC**             | 光敏、热敏、电位器、灰度循迹、模拟雨量、脉搏波      |
| **GPIO输入**        | 数字型循迹模块、简单雨量、红外避障传感器            |
| **输入捕获（TIM）** | 超声波测距、测速传感器、霍尔传感器反馈              |
| **PWM输出（TIM）**  | 舵机、无刷电机、步进电机脉冲                        |
| **I2C**             | OLED显示、温湿度（SHT20等）、心率传感器（MAX30102） |
| **SPI**             | SD卡、部分OLED/TFT屏，NRF24L01 无线模块             |
| **UART**            | GPS模块、GPRS模块、部分蓝牙模块（HC-05）            |



| 模块组合                       | 推荐学习外设                   | 推荐项目示例                   |
| ------------------------------ | ------------------------------ | ------------------------------ |
| 光敏 + 热敏 + OLED显示         | ADC + I2C                      | 简单**环境监测仪**             |
| 循迹模块 + 舵机 + 超声波       | ADC + PWM + 输入捕获           | **避障循迹智能小车**           |
| 心率 + 温湿度 + OLED + SD卡    | I2C + ADC + SPI                | **健康监测设备**               |
| 舵机 + 无刷电机 + NRF24L01无线 | PWM + SPI + 输入捕获           | **远程控制小型机器人**         |
| 超声波测距 + 显示 + MQTT上传   | 输入捕获 + I2C + USART（WiFi） | **IoT远程测距设备 → 云端展示** |
