## Serial Communication



1. 基本概念

   - 全双工：双线同时收发数据（如TX和RX，电话）

   - 半双工：单线分时收发数据（IIC、对讲机）

   - 同步：需要共享时钟信号来同步数据（SPI-SCK,IIC-SCL, 同步串口）

   - 异步：无时钟信号，依赖波特率和帧格式（RS232,RS-485）

     | 接口  | 全双工 | 同步/异步 | 硬件流控 | 最高波特率         | 典型应用            |
     | :---- | :----- | :-------- | :------- | :----------------- | :------------------ |
     | USART | 是     | 同步/异步 | 支持     | 4.5 Mbps (USART1)  | 通用串口通信        |
     | UART  | 是     | 异步      | 可选     | 2.25 Mbps          | 简单异步通信        |
     | SPI   | 是     | 同步      | 不支持   | 18 Mbps            | 高速外设（如Flash） |
     | I2C   | 半双工 | 同步      | 不支持   | 400 kHz (标准模式) | 低速传感器          |

2. 标准串口（USRAT / UART）

   - **全双工异步通信**（UART模式）

   - **半双工单线通信**

   - **同步模式**（需时钟线，仅USART支持）

   - **硬件流控制**（CTS/RTS）

   - **多处理器通信**

   - **LIN总线支持**

   - **红外编码解码**（IrDA）

   - 串口引脚分布

     | 串口   | TX引脚      | RX引脚      | 备注                  |
     | :----- | :---------- | :---------- | :-------------------- |
     | USART1 | PA9 (默认)  | PA10 (默认) | 可重映射到PB6/PB7     |
     | USART2 | PA2 (默认)  | PA3 (默认)  | 可重映射到PD5/PD6     |
     | USART3 | PB10 (默认) | PB11 (默认) | 可重映射到PC10/PC11等 |
     | UART4  | PC10 (默认) | PC11 (默认) | 仅中/大容量型号支持   |
     | UART5  | PC12 (默认) | PD2 (默认)  | 仅中/大容量型号支持   |

3. 其他串行通信串口

   - **SPI**（同步外设接口）：全双工高速通信，常用于存储器、传感器等。
     - 通常有 **2~3个SPI**（如SPI1, SPI2, SPI3）。
   - **I2C**（Inter-Integrated Circuit）：半双工，用于低速设备（如EEPROM）。
     - 通常有 **2个I2C**（如I2C1, I2C2）。
   - **CAN**（控制器局域网）：用于工业通信（如CAN1.0/2.0B）。
