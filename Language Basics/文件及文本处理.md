# 文件及文本处理

## 文本处理函数

| 函数名                      | 功能                                | 示例说明                                   |
| --------------------------- | ----------------------------------- | ------------------------------------------ |
| `strlen(s)`                 | 返回字符串长度（不含 `'\0'`）       | `strlen("abc") → 3`                        |
| `strcpy(dest, src)`         | 拷贝字符串                          | 把 `src` 内容复制到 `dest`                 |
| `strncpy(dest, src, n)`     | 拷贝前 n 个字符                     | 常用于避免越界                             |
| `strcat(dest, src)`         | 连接字符串                          | `"abc" + "def" → "abcdef"`                 |
| `strncat(dest, src, n)`     | 连接 n 个字符                       | 控制连接长度                               |
| `strcmp(s1, s2)`            | 比较字符串                          | 相等返回 0；s1 > s2 返回正；s1 < s2 返回负 |
| `strncmp(s1, s2, n)`        | 比较前 n 个字符                     | 常用于前缀判断                             |
| `strchr(s, c)`              | 查找字符 c 在字符串中的首次出现位置 | 返回指针                                   |
| `strrchr(s, c)`             | 查找字符 c 最后一次出现的位置       | 返回指针                                   |
| `strstr(s, sub)`            | 查找子串                            | `"hello world"` 中查 `"world"`             |
| `sprintf(buf, "格式", …)`   | 把格式化内容写入字符串              | `sprintf(s, "num=%d", 5)`                  |
| `sscanf(str, "格式", …)`    | 从字符串中读取格式化数据            | `sscanf("x=15", "x=%d", &a)`               |
| `memcpy(dest, src, n)`      | 拷贝内存区域                        | 二进制数据、结构体常用                     |
| `memset(ptr, val, n)`       | 填充内存                            | 初始化数组或结构体                         |
| `strtok(str, "分隔符")`     | 分割字符串                          | 类似 `split()` 功能                        |
| `tolower(c)` / `toupper(c)` | 字母大小写转换                      | 需 `<ctype.h>`                             |

## 文件处理函数

| 函数                                              | 功能     |
| ------------------------------------------------- | -------- |
| `FILE *fopen(const char *path, const char *mode)` | 打开文件 |
| `int fclose(FILE *fp)`                            | 关闭文件 |

| 模式                   | 含义                         |
| ---------------------- | ---------------------------- |
| `"r"`                  | 以只读方式打开文本文件       |
| `"w"`                  | 以写入方式打开（清空原文件） |
| `"a"`                  | 以追加方式写入（保留原内容） |
| `"r+"`                 | 可读写，不清空文件           |
| `"w+"`                 | 可读写，清空文件             |
| `"a+"`                 | 可读写，追加写入             |
| `"rb"`, `"wb"`, `"ab"` | 二进制文件读写               |

| 函数                                                         | 功能           | 示例                  |
| ------------------------------------------------------------ | -------------- | --------------------- |
| `fgetc(FILE *fp)`                                            | 读取一个字符   | `char c = fgetc(fp);` |
| `fputc(int c, FILE *fp)`                                     | 写一个字符     | `fputc('A', fp);`     |
| `fgets(char *buf, int size, FILE *fp)`                       | 读一行字符串   | 常用于文本文件        |
| `fputs(const char *s, FILE *fp)`                             | 写一行字符串   | 自动加 `\n` 可选      |
| `fprintf(FILE *fp, "格式", …)`                               | 写格式化内容   | 类似 `printf()`       |
| `fscanf(FILE *fp, "格式", …)`                                | 读格式化内容   | 读入数字或字符串      |
| `fread(void *ptr, size_t size, size_t nmemb, FILE *fp)`      | 读取二进制数据 | 常用于结构体读写      |
| `fwrite(const void *ptr, size_t size, size_t nmemb, FILE *fp)` | 写入二进制数据 | 保存配置或记录        |

| 函数                                       | 功能                     |
| ------------------------------------------ | ------------------------ |
| `ftell(FILE *fp)`                          | 获取当前位置（字节偏移） |
| `fseek(FILE *fp, long offset, int origin)` | 移动文件指针             |
| `rewind(FILE *fp)`                         | 文件指针重置到开头       |
| `feof(FILE *fp)`                           | 判断文件是否到达结尾     |
| `ferror(FILE *fp)`                         | 检查文件是否出错         |
| `remove("file.txt")`                       | 删除文件                 |
| `rename("old.txt", "new.txt")`             | 重命名文件               |

## 常用写法

### 常见组合

```C
// 读取整个文件内容
FILE *fp = fopen("read.txt", "r");
char line[256];
while (fgets(line, sizeof(line), fp)) {
    printf("%s", line);
}
fclose(fp);


// 写入文本
FILE *fp = fopen("log.txt", "w");
fprintf(fp, "温度=%.2f°C\n", 25.3);
fclose(fp);

// 二进制写入/读取结构体
typedef struct {
    int id;
    float value;
} Data;

Data d = {1, 3.14};
FILE *fp = fopen("data.bin", "wb");
fwrite(&d, sizeof(Data), 1, fp);
fclose(fp);

fp = fopen("data.bin", "rb");
fread(&d, sizeof(Data), 1, fp);
printf("id=%d, value=%.2f\n", d.id, d.value);
fclose(fp);

```



| 场景                         | 示例函数                                     |
| ---------------------------- | -------------------------------------------- |
| 逐行读取配置文件并提取键值对 | `fgets()` + `strtok()` + `strcmp()`          |
| 解析 CSV 文件                | `fgets()` + `strtok()` + `atoi()` / `atof()` |
| 写日志                       | `fopen("a")` + `fprintf()`                   |
| 保存传感器数据到文件         | `fwrite()`                                   |
| 从文件加载配置               | `fread()` + 结构体                           |
