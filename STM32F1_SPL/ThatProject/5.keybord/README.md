# 设置

## 硬件外观

- 键盘布局：87键

- 主芯片：STM32F103CBT6

- 供电芯片：BQ24075

- 扫描芯片：74HC165

- 2.4G、蓝牙： nrf52805(同雷蛇)

- RGB灯珠：6028RGB 贴片(同雷蛇)

- 机械轴体：凯华线性红轴（[CPG1511F01S108](http://www.kailh.com/product/Ms/Kh/205.html)）、凯华段落茶轴（[CPG1511F01S109](http://www.kailh.com/product/Ms/Kh/204.html)）

- 静音轴体：凯华段落轴 - 鲸落（[CPG1511F01S172](http://www.kailh.com/product/Ms/Kh/207.html)）、凯华线性轴 - 孤岛（[CPG1511F01S129](http://www.kailh.com/product/Ms/Kh/206.html)）

  

87键、三模键盘（蓝牙、2.4G、有线），主芯片STM32F103CBT6，键盘扫描使用74HC165-D，2.4G和蓝牙使用nrf52840，轴体使用凯华红轴或者凯华茶轴，供电模块使用**BQ24075**主控，兼容USB和3.7V电池供电，RGB使用6028RGB灯珠，请给出一个更加具体设计方案
